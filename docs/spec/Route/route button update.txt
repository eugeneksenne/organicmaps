## Native Navigation System (Organic Maps Foundation)

**Version 4.0 — Production Architecture**

---

# Vision

The Route button is a universal navigation entry point available everywhere in FOMO.

Unlike traditional navigation apps, FOMO combines **native navigation**, **social intelligence**, and **live venue data** into a single experience.

Users are always free to choose their preferred navigation app, but **FOMO Navigation (powered by Organic Maps)** is recommended because it provides the richest experience.

The Route Engine is built on:

* Organic Maps (native navigation engine)
* OpenStreetMap (map data)
* OSRM (routing engine)
* FOMO Venue Intelligence
* FOMO Social Intelligence
* NightGuard Safety

This preserves user choice while making the in-app experience the best option.

# Live Crowd Intelligence

Instead of queue estimates, FOMO uses community-powered crowd updates.

Users currently at the venue occasionally receive a lightweight prompt.

```
🔥 Help others discover tonight's vibe

How's the crowd?

🟢 Low Key

🟡 Building

🟠 Lit

🔴 Legendary

Submit
```

The popup appears intelligently, for example:

* After spending time at the venue
* After posting a Moment
* After checking in
* While browsing the Club Lobby

To maintain quality:

* Only users at the venue can respond.
* One update every 30–60 minutes.
* Responses expire over time so the displayed crowd reflects current conditions.
