Motion System

Organic Maps remains continuously rendered between screens to avoid reloads.

Venue cards fade and resize smoothly between preview, navigation, and arrival.

Route lines animate when switching between alternative routes.

Crowd and friend updates animate in place instead of using intrusive pop-ups.

Arrival transitions use a subtle hero image reveal and card expansion rather than dramatic effects.

Complete Navigation Flow

📍 Route │ ▼ Navigation App Picker │ ▼ Transport Selection │ ▼ Route Preview │ ▼ Active Navigation │ ▼ Mini Navigation (optional) │ ▼ Arrival Experience │ ▼ Crowd Update (venue users only) │ ▼ Navigation Summary 

This updated UI keeps the destination venue at the heart of the experience. Organic Maps handles navigation, while FOMO continuously layers in venue intelligence, friend presence, NightGuard safety, and community-powered crowd updates, creating a navigation flow that feels native to a social nightlife platform rather than a conventional maps application.
