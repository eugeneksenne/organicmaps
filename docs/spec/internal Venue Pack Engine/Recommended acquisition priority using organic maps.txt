```text
Offline map rendering
Offline search
Geographic context
Map data consumption
Routing/navigation infrastructure
Mobile map functionality
```

Organic Maps is an offline maps application powered by OSM data. ([GitHub][1])

Do not treat Organic Maps as if it were a commercial venue API.

```text
Planet OSM
Geofabrik extracts
OSM-compatible datasets
```

# Field-level source provenance

This is something I strongly recommend making **mandatory**.

Never store only:

```text
opening_hours = "09:00-02:00"
```

Store provenance as well:

```text
opening_hours:
    value: "09:00-02:00"
    source: GOOGLE
    source_id: "..."
    confidence: 0.94
    observed_at: "..."
    verified_at: "..."
```

Likewise:

```text
coordinates:
    source: OSM

phone:
    source: GOOGLE

instagram:
    source: COMMUNITY

hero_image:
    source: VENUE_OWNER
```

This creates a proper **Field Provenance Engine**.

# Source conflict example

Suppose:

```text
OSM:
Opening hours = 18:00-02:00
Updated = 3 months ago

Google:
Opening hours = 18:00-03:00
Updated = 4 days ago

Community:
Opening hours = 18:00-03:00
Updated = yesterday
```

The engine should not blindly use:

```text
OSM
```

because OSM was designated the "primary" source.

Instead:

```text
Field = Opening Hours

OSM       → 3 months old
Google    → 4 days old
Community → 1 day old
```

Result:

```text
Canonical:
18:00-03:00

Provenance:
COMMUNITY + GOOGLE

Confidence:
HIGH
```

That's much more intelligent.

## One more important point

I would also **not promise "OSM supplies 80-95% of the venue database" as a hard requirement**.

That can vary enormously by country, city and venue category. OSM is an excellent global foundation, but coverage and attribute completeness are heterogeneous. OSM's own distribution mechanisms provide the raw geographic dataset, while Organic Maps uses OSM for its offline maps. ([OpenStreetMap][2])

Make it a **target/optimization objective**, not an invariant:

```text
TARGET:

Maximize OSM-derived venue coverage.

Minimize commercial API calls.

Never sacrifice venue quality merely to increase OSM percentage.
```

That is a much better production rule.
