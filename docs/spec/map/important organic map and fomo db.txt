## 1. Where does Organic Maps store its map data?

Organic Maps downloads map packages onto the **device's local storage** and uses those local files for offline maps, search and routing. Its Android app supports storing downloaded maps in internal private storage or other available storage, including SD storage on supported devices. ([Organic Maps][1])

So when someone downloads:

```text
South Africa
   └── Mpumalanga
```

the actual geographic map data ends up **on that user's phone**, not in Supabase.

That is exactly what you want for FOMO's offline map capability.

The important point is that Organic Maps does not normally work like:

```text
Supabase
   ↓
Organic Maps
   ↓
Map
```

Instead it is more like:

```text
Map package download
        ↓
PHONE STORAGE
        ↓
Organic Maps engine
        ↓
Map / Search / Routing
```

Organic Maps also publishes map-data resources/mirrors, and its current releases continue to use regularly updated OSM data. ([Organic Maps][2])
