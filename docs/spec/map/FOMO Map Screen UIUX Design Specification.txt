# FOMO Map Screen UI/UX Design Specification

## Billion-Dollar Standard (Version 3.0)

> ## Product Vision
>
> The FOMO Map is **not** a navigation app.
>
> It is the **live operating system of the city's social energy.**
>
> Unlike traditional maps that show roads and places, the FOMO Map visualizes **where life is happening right now.**
>
> Within five seconds, every user should know:
>
> * Where should I go?
> * What's happening nearby?
> * What's worth visiting?
> * How do I get there?
>
> The experience should feel alive every second.

---

# Design Philosophy

The Map should feel like a fusion of

* Apple Maps
* Uber
* Tesla
* Spotify
* Airbnb

while remaining unmistakably **FOMO**.

The experience must be

* Live
* Premium
* Beautiful
* Intelligent
* Minimal
* Context-aware
* One-handed
* Fast

Every animation should communicate activity.

Every interaction should reduce friction.

# Floating Action Stack

Positioned on the right side of the Interactive Live Map.

Uses floating glass buttons with equal spacing and soft elevation.

```text

🛡 Night Guard

◎ Recenter
```

---

# Add Venue

## Purpose

Allows users to add venues that are not currently available on the FOMO Map, helping expand the venue database through community contributions.

---

## Behaviour

Tapping **Add Venue** launches the dedicated **FOMO Add Venue** workflow.

The complete user flow, validation, moderation process, and submission experience are defined in the **FOMO Add Venue Specification**.

The Map screen serves only as the entry point.

---

## Integration

Approved venues automatically become available throughout the FOMO ecosystem, including:

* Discover
* Map
* Search
* Club Lobby
* Creator Studio (when claimed)
* Events
* Flash Drops

---

# Night Guard

## Purpose

Provides users with access to FOMO's dedicated nightlife safety platform.

---

## Behaviour

Tapping **Night Guard** launches the dedicated **FOMO Night Guard** experience.

All safety tools, emergency features, trusted contacts, reporting, and additional capabilities are defined in the **FOMO Night Guard Specification**.

The Map screen serves only as the entry point.

# Final Experience

The FOMO Map should make users feel connected to the city's energy the moment it opens. The **Nearest Venue Card** immediately highlights the closest destination, the **Interactive Live Map** visualizes activity across the city, and the **Nearby Venue Cards Carousel** enables seamless exploration while staying synchronized with the map. The streamlined **Floating Action Stack**—**Add Venue**, **Night Guard**, and **Recenter**—keeps the interface focused while integrating with dedicated specifications for venue submissions and nightlife safety. Every animation, glow, transition, and interaction should reinforce a single goal: helping users confidently discover where to go next while making the city feel alive in real time.
