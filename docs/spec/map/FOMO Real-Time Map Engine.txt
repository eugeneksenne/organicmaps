Instead of subscribing to the entire country, subscribe only to relevant H3 cells.

Current Location ↓ Generate H3 Cell ↓ Subscribe to Cell ↓ Move to Next Cell ↓ Unsubscribe Old Cell ↓ Subscribe New Cell

Architecture recommendation

Since you've already standardized on native Kotlin with shared logic and Supabase, I would make Supabase Realtime (Presence, Broadcast, and Postgres Changes) the default transport for nearly all map updates because it integrates directly with your backend and simplifies operations. Reserve Socket.IO for features that demand extremely high-frequency, bidirectional messaging—such as collaborative map interactions or live multiplayer experiences—where its event model provides an advantage. This hybrid approach minimizes infrastructure complexity while preserving the flexibility to support future high-scale realtime features.
