# ENGINEERING PRINCIPLES

* Never hardcode business logic into the UI.
* All Discover sections must be remotely configurable.
* Every feature must degrade gracefully offline.
* Every list must support pagination.
* Every API must support filtering and cursor pagination.
* Every image must support progressive loading.
* Every animation must remain at 60 FPS.
* Every recommendation must explain *why* it was made where appropriate.
* Every component must be modular, reusable, and independently deployable.
* Optimize for maintainability, observability, scalability, and production reliability.

# SUCCESS CRITERIA

The completed Discover feature should feel comparable in quality and responsiveness to the best consumer apps (such as TikTok, Spotify, Airbnb, and Uber), while remaining uniquely focused on real-time nightlife discovery. It should support millions of users, real-time updates, feature flags, A/B testing, and future expansion without requiring architectural rewrites.
