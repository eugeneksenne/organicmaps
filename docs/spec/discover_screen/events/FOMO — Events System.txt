# FOMO Events System

## Premium Production Specification 

---

# Vision

The FOMO Events section is not an event marketplace.

It is a **premium nightlife discovery and planning engine** that helps users answer one question:

> **"Where should I go tonight?"**

Everything is designed around:

* Discovery
* Planning
* Venue-first experiences
* Fast decision making
* Beautiful UI
* Premium interactions

---

# Core Principles

The Events screen should always feel:

* Premium
* Cinematic
* Fast
* Spacious
* Venue-first
* Social
* Trustworthy

Avoid:

* Clutter
* Tiny text
* Marketplace layouts
* Information overload

# Calendar

The calendar is accessed **only** from the 📅 icon.

The Events screen never switches into calendar mode.

This keeps discovery fast while allowing long-term planning.

The calendar contains:

* Month view
* Event indicators
* Day timeline
* My Plans
* Ticket reminders
* Festivals
* Public holidays
* Upcoming weekends

# Event Sorting

Events are intelligently ranked.

Priority:

1. Distance
2. Starts soon
3. Live now
4. Ripple Heat
5. Venue quality
6. Ticket availability
7. Sponsored events (clearly labeled)

This ensures nearby events that are about to begin appear first.

# Club Lobby Integration

Every nightlife event is linked to its venue's Club Lobby.

Users can instantly:

* View live moments
* See venue activity
* Join conversations
* View active Flash Drops
* Explore other events at the venue

# Flash Drop Integration

If the venue has an active Flash Drop, the preview displays:

Available until 23:30

Claim at Venue

# Personalization

The Events screen adapts based on:

* Time of day
* User location
* Preferred music genres
* Ripple Heat
* Venue status
* Distance
* Ticket availability

Behavior:

* Daytime → **All** selected by default.
* From 18:00 onward → **Tonight** selected automatically.

# Final User Journey

**Discover → Events → Floating Event Preview → Tickets / Route / Club Lobby / Plan / Reminder / Share → Event Details → Venue Experience**

This creates a seamless nightlife journey where users can discover an event, plan it, navigate to the venue, engage with the Club Lobby, and participate in the nightlife experience—all without the Events section ever feeling like a traditional ticket marketplace.
