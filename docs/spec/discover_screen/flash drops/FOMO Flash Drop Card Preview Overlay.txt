FOMO Flash Drop Card Preview Overlay

Full UI/UX Specification

The uploaded reference establishes the Flash Drop card preview as a full-screen vertical overlay, rather than another card inside the Discover feed.

Its purpose is to give the user the complete context of a Drop and provide the four contextual actions without cluttering the Discover card.

Immediately underneath the header is a horizontal pagination indicator.

Example:

The active Drop is highlighted.

This communicates that the user can move between active Drops.

Horizontal swipe → next/previous Flash Drop

4. Hero media

The hero occupies the dominant portion of the upper screen.

Content

Can be:

Event photography

Live nightlife imagery

Treatment

Use:

6. Countdown

The countdown is one of the strongest elements of the preview.

Example:

18:42 TIME LEFT 

For a Drop that has not started:

01:42:15 STARTS IN 

For an active Drop:

00:42:15 TIME LEFT 

Critical timing rule

The countdown must be calculated from the actual Flash Drop schedule.

For example:

Flash Drop: 19:00 → 21:00 

If the current time is:

18:17 

the preview displays:

STARTS IN 00:43:00 

At 19:00 it transitions to:

TIME LEFT 02:00:00 

At 21:00:

EXPIRED 

This prevents the countdown from becoming an arbitrary decorative number.

12. Dynamic Drop tags

Below the offer:

🔥 TRENDING 🌙 TONIGHT ONLY ✨ LIMITED 

These are secondary discovery signals.

A Drop can have multiple states simultaneously.

13. Action icon row

This is the major feature established in the reference.

Four contextual actions:

CLUB LOBBY 🏢 ROUTE ➤ REMINDER 🔔 PLAN 📅 

1. Club Lobby

Opens the venue's Club Lobby.

Relevant primarily for Venue Drops.

2. Route

Opens the FOMO routing experience.

3. Reminder

Creates a reminder for the Drop.

4. Plan

Opens the FOMO planning flow.

These actions belong to the Flash Drop preview, not the compact Discover card.

14. Save

Bottom-left:

♡ SAVE

This is separate from the four contextual action buttons.

The user can save/like the Drop without entering another flow.

When selected:

♡ 

becomes:

♥ 

The saved state should persist.

15. Nearby

Bottom-right:

◉ NEARBY

This allows the user to move toward nearby Flash Drops.

It reinforces the location-based nature of Flash Drops.

16. Swipe navigation

The center bottom instruction:

⌃ SWIPE UP FOR NEXT DROP 

The user can swipe vertically to move through active Drops.

The reference uses:

1 / 6 

to show the current position.

So:

1 / 6 2 / 6 3 / 6 ... 6 / 6 

17. Interaction model

From Discover

Flash Drop card ↓ TAP ↓ Full-screen preview 

Within preview

SWIPE UP ↓ Next Flash Drop SWIPE DOWN ↓ Previous Flash Drop TAP LIKE ↓ Save / unsave TAP SHARE ↓ Share flow TAP CLUB LOBBY ↓ Club Lobby TAP ROUTE ↓ Route TAP REMINDER ↓ Reminder TAP PLAN ↓ Plan

19. Important timing states

The UI should automatically transition based on the schedule.

Before Drop

STARTS IN 00:42:15 

Active

TIME LEFT 01:42:15 

Ending soon

TIME LEFT 00:07:24 

Expired

The Drop should no longer appear in the active Flash Drops stack.
