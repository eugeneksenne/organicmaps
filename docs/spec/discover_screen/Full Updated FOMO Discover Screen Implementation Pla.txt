# FOMO Discover Screen

## 1. Dynamic Hero

**Purpose**

The emotional entry into your city's nightlife.

The Hero is dynamic and changes throughout the day.

### Displays

* Cinematic city background
* Dynamic headline
* Weather
* City Energy Meter
* Live venue count
* Live event count
* Flash Drop count
* Friend activity summary
* AI recommendation
* Primary CTA

**No "See All" button.**

---

# 9. Explore the City

**Purpose**

Browse nearby venues using the same categories as the FOMO Venue Packs.

There is **no separate Categories section** on Discover.

### Categories

Horizontal scrolling chips.

```text
[All] [Nightlife] [Food] [Prep] [Travel] [24/7]
```

### Venue Row

A single horizontal row of premium venue cards.

```text
Explore the City                    See All →

[All] [Nightlife] [Food] [Prep] [Travel] [24/7]

────────────────────────────────────────────

◀ Venue • Venue • Venue • Venue • Venue ▶
```

### Sorting

Venues are always sorted by **distance from the user's current location**.

**All**

* Nearest venues across every installed venue pack.

**Nightlife**

* Clubs
* Lounges
* Bars
* Rooftops

**Food**

* Restaurants
* Fast food
* Cafés
* Desserts

**Prep**

* Barber
* Salon
* Beauty
* Fashion
* Makeup

**Travel**

* Hotels
* Airports
* Transport
* Car rental

**24/7**

* Venues currently operating 24 hours.

### Navigation

**See All → Explore the City Screen**

# Navigation Pattern

Every section below the Hero follows the same interaction model:

```text
Section Title                     See All →

Preview (Horizontal Scroll)

↓

Dedicated Screen

↓

Search (where applicable)

↓

Filters

↓

Full Experience
```

---

# Final Discover Screen Structure

```text
Dynamic Hero

↓

Closing Soon
(Horizontal Preview)
See All →

↓

Flash Drops
(Horizontal Preview)
See All →

↓

My Circle
(Horizontal Profile Cards)
See All →

↓

Live Moments
(Horizontal Preview)
See All →

↓

Smart Places
(Horizontal Venue Cards)
See All →

↓

Trending Now
(Horizontal Preview)
See All →

↓

Events
(Horizontal Event Cards)
See All →

↓

Explore the City
(Category Chips)

[All] [Nightlife] [Food] [Prep] [Travel] [24/7]

(Horizontal Venue Cards sorted by distance)

See All →

↓

Channels
(Horizontal Preview)
See All →

↓

Prep Rooms
(Horizontal Preview)
See All →

↓

Tonight
(Horizontal Preview)
See All →
```

This updated structure keeps the Discover screen focused as a **preview hub**: every section presents a concise horizontal preview, while **See All** leads to a dedicated screen with richer browsing and filtering. The result is a clean, consistent navigation model that scales well without overcrowding the main Discover experience.
