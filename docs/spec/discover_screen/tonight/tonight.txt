# FOMO Discover Screen — “tonight” Full Implementation Plan

The **tonight** section is FOMO’s operational nightlife layer.

It combines:

* planning
* safety
* coordination
* realtime nightlife awareness
* intelligent assistance

This section is designed to feel like:

> a premium nightlife operating system

NOT:

> a utility dashboard

It should feel:

* alive
* adaptive
* cinematic
* effortless
* socially aware

# Core Architecture

MyMovesEngine
 ├── NightGuardModule
 ├── PlansModule
 ├── ContextEngine
 ├── RealtimeStatusEngine
 └── SmartSuggestionsEngine
```

Each engine powers the UI invisibly.

The user experiences:

* smooth actions
* intelligent coordination
* realtime nightlife assistance

---

# Engine Responsibilities

---

# 1. NightGuardModule

The protection system.

Handles:

* trusted contacts
* emergency triggers
* inactivity monitoring
* live safety tracking
* route awareness
* safe arrival verification
* group separation alerts

---

# 2. PlansModule

The nightlife coordination engine.

Supports:

* solo plans
* duo plans
* group nightlife plans
* venue timelines
* invitations
* realtime plan syncing
* shared nightlife movement

Architecture:

```txt id="ji4fy4"
PlansModule
 ├── SoloPlansEngine
 ├── DuoPlansEngine
 ├── GroupPlansEngine
 ├── InvitationsEngine
 ├── SharedTimelineEngine
 ├── VenueRoutingEngine
 ├── PresenceEngine
 ├── RealtimeSyncEngine
 └── PlansChatEngine
```

---

# 3. ContextEngine

The adaptive intelligence system.

Tracks:

* time
* nightlife density
* user behavior
* social proximity
* weather
* venue activity
* movement patterns

This engine personalizes the entire Discover screen.

---

# 4. RealtimeStatusEngine

Makes FOMO feel alive.

Handles:

* live venue changes
* friend movement
* plan updates
* NightGuard status
* live arrivals
* queue conditions
* ride activity

Without this:
FOMO feels static.

---

# 5. SmartSuggestionsEngine

The predictive nightlife intelligence layer.

Generates:

* venue recommendations
* timing suggestions
* queue avoidance
* traffic optimization
* nightlife predictions
* safety suggestions

Examples:

```txt id="d95w51"
Leave now to avoid queue surge at LIV.
```

```txt id="wkqj54"
Bolt prices rising near Rosebank.
```
