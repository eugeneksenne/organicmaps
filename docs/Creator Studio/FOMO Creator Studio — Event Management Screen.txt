I think the **Event Management Screen** should be the heart of Creator Studio.

Creating an event is something creators do occasionally. **Managing events is what they'll do every day.**

This screen shouldn't feel like a CRUD table—it should feel like an **operations center** for running nightlife events.

---

# FOMO Creator Studio — Event Management Screen

## Product Vision

The **Event Management Screen** is the central workspace for managing every event created within FOMO.

It provides creators with a comprehensive overview of all events, their current status, operational health, and performance, while enabling quick access to every aspect of event management.

This screen serves as the primary operational hub for Venue Owners and Event Organisers.

---

# Design Principles

The screen should be:

* Mobile-first
* Fast to navigate
* Action-oriented
* Status-driven
* Visual
* Searchable
* Intelligent

Creators should never need to open an event just to know what's happening.

# Smart Suggestions

The screen can surface proactive recommendations.

Examples:

> Your event "Neon Fridays" is missing a Flash Drop.

> Ticket sales are slower than your recent average.

> This event doesn't have any confirmed performers yet.

> Your event is scheduled for tomorrow but hasn't been published.

These appear as non-intrusive insight cards above the event list.

# Integrations

Every event acts as the parent object for:

* Venue
* Tickets
* Flash Drops
* Marketing
* Lineup
* Guest Lists
* Intelligence
* Notifications

Changes in these modules are reflected immediately on the Event Management Screen.

---

# Success Metrics

The Event Management Screen should allow creators to:

* See the status of every event at a glance.
* Take common actions without unnecessary navigation.
* Identify operational issues quickly.
* Access all event-related tools from a single place.
* Manage multiple events efficiently.

---

# Guiding Principle

**The Event Management Screen should feel like an event command center, not a list of events.** Every event card should communicate its operational health through status, ticket sales, Flash Drops, lineup progress, and key actions, enabling creators to manage their nightlife business efficiently from a single, intelligent workspace.
