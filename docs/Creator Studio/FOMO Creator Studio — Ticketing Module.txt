# FOMO Creator Studio — Ticketing Module

## Product Vision

The **Ticketing Module** is the complete ticket operations platform for FOMO Creator Studio.

Its purpose is not only to sell tickets, but to manage the **entire ticket lifecycle**—from ticket creation and sales to guest check-in, refunds, reporting, and post-event reconciliation.

Ticketing is deeply integrated with the Events Module. Creators configure ticket types inside an event, while the Ticketing Module provides a centralized operational view across all events.

This makes Ticketing the **business operations hub** for admissions and event access.

---

# Design Principles

The Ticketing Module should be:

* Event-centric, with tickets created within event workspaces.
* Operational, giving creators one place to manage sales and admissions.
* Secure, protecting against fraud and duplicate entries.
* Mobile-first, allowing door staff and organisers to work from anywhere.
* Reliable, supporting offline scanning and automatic synchronization.

# Guiding Principle

The Ticketing Module should feel like **running the front door of a professional nightlife venue**, not simply processing transactions. While ticket types are created as part of an event, this module becomes the operational control center where creators monitor sales, manage admissions, validate guests, issue refunds, and understand the financial performance of every event. It should provide the speed and reliability needed on event night while delivering the insights required to improve future events.
