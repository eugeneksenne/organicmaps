# FOMO Creator Studio (Updated Vision)

## Product Vision

**FOMO Creator Studio is not a social media creator platform.**

It is the **operating system for the nightlife industry**, designed exclusively for verified nightlife professionals who create, manage, and grow nightlife experiences.

Creator Studio serves as the professional backend for the FOMO ecosystem, while the consumer FOMO app remains focused on discovering nightlife.

---

# Core Principles

Every feature must answer one question:

> **Does this help someone create, manage, or grow nightlife experiences?**

If the answer is no, it doesn't belong.

---

# Long-Term Vision

FOMO Creator Studio is not simply an admin dashboard. It is the **professional operating system for nightlife**.

It brings together venues, organisers, DJs, artists, ticketing, promotions, Flash Drops, analytics, and collaboration into a single platform that powers the entire nightlife ecosystem. By focusing on verified professional identities, role-based workflows, and shared event management, Creator Studio becomes the place where nightlife businesses operate—not just where they publish events.
