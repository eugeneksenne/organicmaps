
# FOMO Ownership Intelligence

## Product Vision

The Ownership Intelligence Engine continuously analyzes a user's authenticated identities and compares them with venue records to identify likely ownership matches.

When a high-confidence match is found, FOMO proactively offers the user the opportunity to claim the venue.

The system should never expose private business information or silently assign ownership.

---

# Example 1 — Google Login

A user logs into FOMO with:

```
clubxyz@gmail.com
```

Google Places data for a venue contains:

```
Business Email

clubxyz@gmail.com
```

Ownership Intelligence detects a 100% match.

Instead of asking the user to search manually, FOMO shows:

> **We found a venue that may belong to you.**

```
Sky Lounge

Johannesburg

✓ Verified Business Match

[ Claim Venue ]
```

The user taps **Claim Venue**.

Ownership is granted instantly (assuming all other checks pass).

# Important Safeguards

I would add these rules:

* Never auto-assign ownership without the user's confirmation.
* Never reveal hidden business contact details while suggesting a claim.
* If a venue is already claimed, offer **Request Ownership Transfer** instead of a direct claim.
* Log every automatic claim recommendation for auditing.
* Re-evaluate claim suggestions whenever a user adds a new verified login method.

---

# A Better Name

I would avoid calling it **Auto Claim**, because that suggests ownership changes happen without user involvement.

Instead, call it:

* **Smart Claim**
* **Instant Claim**
* **Ownership Intelligence**
* **Verified Claim**
* **Claim Suggestions**

For example:

> **Ownership Intelligence found a venue associated with your verified account. Would you like to claim it?**

This feels intentional and trustworthy.

## My Recommendation

Build a dedicated **Ownership Intelligence Engine** that runs in the background whenever a user:

* Signs in.
* Links a new Google account.
* Changes their email or phone number.
* Completes Venue Owner verification.

It continuously compares verified identities against venue records and surfaces high-confidence claim opportunities. This makes onboarding almost effortless for legitimate venue owners while preserving an explicit confirmation step before ownership is granted. That combination of convenience and security is likely to scale much better as FOMO grows.
